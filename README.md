# Menú Colmado

Aplicación de escritorio desarrollada en C# con Windows Forms para simular un menú de un colmado y facilitar la selección de productos y el cálculo de una compra.

## Descripción

El proyecto presenta una interfaz gráfica donde el usuario puede seleccionar opciones del menú, elegir el método de pago y utilizar el botón de cálculo para procesar la operación.

## Funcionalidades

- Interfaz gráfica para el menú del colmado.
- Selección de productos mediante controles de Windows Forms.
- Selección del método de pago.
- Botón para calcular la compra.
- Diseño sencillo y fácil de utilizar.

## Tecnologías utilizadas

- C#
- .NET 10
- Windows Forms
- Visual Studio

## Estructura principal

- `Form1.cs`: contiene la lógica principal de la aplicación.
- `Form1.Designer.cs`: contiene el diseño de la interfaz.
- `Form1.resx`: contiene los recursos del formulario.
- `Program.cs`: punto de entrada de la aplicación.
- `MenuColmado.csproj`: configuración del proyecto.
- `MenuColmado.slnx`: solución del proyecto.

## Instalación y ejecución

1. Descargar o clonar el repositorio.
2. Abrir `MenuColmado.slnx` en Visual Studio.
3. Compilar el proyecto.
4. Ejecutar la aplicación.

## Objetivo

El objetivo de este proyecto es practicar el desarrollo de aplicaciones de escritorio utilizando C# y Windows Forms, aplicando controles, eventos y lógica básica para crear un sistema de menú para un colmado.

## Estado del proyecto

Proyecto educativo desarrollado con C# y Windows Forms.
